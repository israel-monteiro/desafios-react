# Desafios React

Repositório criado para reunir os desafios e exercícios práticos desenvolvidos durante meus estudos de **React**.

O objetivo é utilizar os desafios para praticar e consolidar conceitos fundamentais do desenvolvimento Front-End, como componentização, propriedades, estados, eventos, hooks, estilização e organização de projetos.

## 📂 Estrutura

Cada desafio possui sua própria pasta dentro deste repositório.

```text
desafios-react/
├── desafio-01/
│   ├── README.md
│   └── ...
├── desafio-02/
│   ├── README.md
│   └── ...
└── desafio-03/
    ├── README.md
    └── ...
```

### 📖 Documentação dos desafios

Cada pasta de desafio possui um **README próprio**, contendo informações específicas sobre o desafio, como:

- Objetivo
- Descrição do problema
- Tecnologias utilizadas
- Conceitos praticados
- Como executar o projeto
- Solução desenvolvida

Dessa forma, este README funciona como a documentação geral do repositório, enquanto cada desafio possui sua própria documentação detalhada.

## 🛠️ Tecnologias

As tecnologias podem variar de acordo com cada desafio, mas o repositório tem como foco principal:

- React
- JavaScript
- HTML
- CSS
- Styled Components

## 🎯 Objetivo

Praticar React de forma progressiva, desenvolvendo pequenos projetos e desafios que permitam aplicar os conceitos estudados na prática.
